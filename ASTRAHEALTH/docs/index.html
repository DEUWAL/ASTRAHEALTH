How this relates to the full project: this page runs the same rule / baseline / risk / alert logic as the Python FastAPI backend (see /backend in the repository), ported to JavaScript so judges can run it in one click without installing anything. The browser demo uses a simple multivariate distance score where the backend uses an Isolation Forest. Anomaly scores are not probabilities of disease; configured thresholds are prototype values, not clinical limits. Offline records are stored in your browser's IndexedDB and are only synchronised to a simulated in-page server.
